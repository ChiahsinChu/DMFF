# ADMPPolarizableElectrodeForce

## 1. Theory

ADMPPolarizableElectrodeForce implements the polarizable electrode method in the style of the LAMMPS `fix electrode` command (constant potential, CONP, and constant charge, CONQ). Electrode atoms carry Gaussian-smeared charges that are equilibrated at every evaluation, while electrolyte atoms keep their fixed point charges.

The total electrostatic energy is

```math
E(q) = E_{pme}(q) + E_{corr}(q) + E_{gauss}(q) + \sum_i \left(\chi_i q_i + J_i q_i^2\right)
```

where $`E_{pme}`$ is the point-charge PME energy (real + reciprocal + self), $`E_{corr}`$ contains the non-neutral background correction $`-\pi Q_{tot}^2 / (2V\kappa^2)`$ and, for 2D systems, the Yeh–Berkowitz slab correction, and $`E_{gauss}`$ is the Gaussian smearing correction of `E_sr3` (see the [Qeq documentation](./4.3ADMPQeqForce.md)):

```math
E_{gauss} = -\sum_{i<j} \mathrm{erfc}\left(\frac{r_{ij}}{\sqrt{\eta_i^2+\eta_j^2}}\right)\frac{q_i q_j}{r_{ij}} + \sum_i \frac{q_i^2}{\eta_i\sqrt{2\pi}}
```

The width parameter follows the `E_sr3` convention: $`\eta_i = 1/\eta_i^{lmp}`$ (in angstrom), where $`\eta^{lmp}`$ is the value used in LAMMPS `fix electrode` (in 1/angstrom). $`\eta_i = 0`$ recovers a point charge (used for electrolyte atoms).

The electrode charges minimize $`E`$ subject to linear constraints:

* **conp**: the applied potential $`\psi`$ enters as $`\chi_i \to \chi_i - \psi`$; with `symm=True`, overall electroneutrality of the electrodes is enforced.
* **conq**: the total charge of each electrode group is constrained to the given value.
* **finite field (ffield)**: for fully periodic (3D) setups, a linear potential ramp $`\Delta\psi \cdot z/L_z`$ is added to $`\chi`$ and the corresponding uniform electric field acts on all charges, reproducing `fix electrode ... ffield yes`.

The constrained minimization is solved either by direct inversion of the KKT system (``method="matinv"``)

```math
\begin{pmatrix} H & A^T \\ A & 0 \end{pmatrix}
\begin{pmatrix} q \\ \lambda \end{pmatrix} =
\begin{pmatrix} -\chi \\ b \end{pmatrix}
```

with $`H = \partial^2 E/\partial q^2`$, or iteratively with L-BFGS on the projected gradient (``method="lbfgs"``). At the optimum the Hellmann–Feynman theorem holds, so forces are the plain derivatives at fixed converged charges.

Positions must be wrapped into the box ($`[0, L)`$, as in LAMMPS): absolute coordinates enter the slab correction and the finite-field potential.

## 2. Frontend

```xml
<ADMPPolarizableElectrodeForce>
    <Atom type="Pt" chi="0.0" J="0.0" eta="0.625"/>
    <Atom type="O" chi="0.0" J="0.0" eta="0.0"/>
</ADMPPolarizableElectrodeForce>
```

Per-atom parameters: electronegativity `chi` [V], hardness `J` [V/e] and Gaussian width `eta` [A] (`= 1/eta_lammps`).

Electrode groups are system specific and passed to `createPotential`:

```python
import numpy as np
import openmm.app as app
import openmm.unit as unit
from dmff.api import Hamiltonian

hamilt = Hamiltonian("electrode.xml")
pot = hamilt.createPotential(
    topology,
    nonbondedMethod=app.PME,
    nonbondedCutoff=0.5 * unit.nanometer,
    electrode_constraints=[
        dict(indices=np.arange(108), mode="conp", value=20.0, eta=1.6),
        dict(indices=np.arange(108, 216), mode="conp", value=0.0, eta=1.6),
    ],
    symm=True,          # electroneutrality of the electrodes
    slab_corr=True,     # 2D systems (extend the box along slab_axis yourself)
    kappa=0.5,          # Ewald splitting [A^-1], optional
    ethresh=1e-6,
    method="matinv",    # or "lbfgs"
    has_aux=True,
)
efunc = pot.getPotentialFunc()
energy, aux = efunc(positions, box, pairs, hamilt.paramset.parameters, aux={})
q_opt = aux["q"]  # equilibrated charges
```

Constraint dict keys: `indices`, `mode` ("conp"/"conq"), `value` (potential [V] for conp, charge [e] for conq), and optionally `eta` [1/A, LAMMPS convention], `chi` [V], `hardness` [V/e], `ffield` (bool). Values given in a constraint override the XML per-type parameters for those atoms; omitted ones (or `eta=0`) fall back to the XML values, which stay differentiable through the `ParamSet`.

The k-mesh is fixed from the topology box when the potential is created; recreate the potential if the box changes. Covalent exclusions are not applied (electrode systems are typically bond-free).

## 3. Backend

The backend in `dmff.admp.electrode` works in angstrom / kJ/mol and can be used directly, mirroring the torch-admp reference implementation:

```python
from dmff.admp.electrode import (
    LAMMPSElectrodeConstraint, PolarizableElectrode, infer, setup_from_lammps,
)

setup = setup_from_lammps(
    n_atoms,
    [
        LAMMPSElectrodeConstraint(np.arange(108), "conp", 20.0, eta=1.6),
        LAMMPSElectrodeConstraint(np.arange(108, 216), "conp", 0.0, eta=1.6),
    ],
    symm=True,
)
calc = PolarizableElectrode(rcut=5.0, box=box, kappa=0.5, slab_corr=True)
energy, forces, q_opt = infer(calc, positions, box, charges, pairs, setup)
```

The implementation is validated against LAMMPS `fix electrode` single-point reference data (`tests/test_admp/test_electrode.py`): forces match within 5e-5 eV/A (slab systems) and 5e-4 eV/A (interface systems) for all conp/conq/ffield variants with both solvers.
